# 📊 Insurance Analytics Project
The Insurance Analytics Project focuses on analyzing insurance policy and customer data to identify premium trends, claim patterns, and customer insights. The project involves data cleaning, analysis, and dashboard development using SQL, Excel, and Power BI/Tableau.

# ⭐ Key Highlights
* Analyzed 5,000+ insurance policy records to study premium trends and claim amounts.
* Performed data cleaning and preparation using SQL and Excel.
* Developed interactive dashboards to track total policies, customers, premiums, and claims.
* Visualized policy distribution by age group, gender, policy type, and payment status.

# 🛠 Tools & Technologies
* SQL
* Microsoft Excel
* Power BI / Tableau

# 📈 Project Outcome
Generated business insights to support insurance performance analysis, customer segmentation, and reporting through interactive dashboards and visualizations.
